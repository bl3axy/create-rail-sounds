# Railroad Roadbed (Fabric 26.2)

Custom Ballast, Weathered Ballast and Cinder Ballast (block + slab + stairs), plus slabs and stairs for gravel, coarse dirt, dirt, sand, red sand, packed mud and clay, for track ballast and embankments.
They don't fall like gravel. Shovel-mineable. In the Building Blocks creative tab.

Recipes: 3 in a row = 6 slabs, stair shape = 4 stairs, 2 slabs stacked = 1 full block back.

Install on the server AND every player's game (it adds blocks).

Ballast recipes: gravel+cobblestone in a 2x2 checker = 4 Ballast. 4 Ballast + coarse dirt = 4 Weathered. 4 Ballast + coal/charcoal = 4 Cinder.
